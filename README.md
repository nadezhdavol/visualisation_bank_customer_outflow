# EDA оттока клиентов банка: Анализ факторов ухода клиентов 🏦

*Учебный проект в рамках программы профессиональной переподготовки «Аналитик данных» (НИУ ВШЭ), 2025–2026.*

## 📌 О проекте

Данный проект выполнен в рамках домашнего задания №8 по курсу «Python для анализа данных» программы переподготовки НИУ ВШЭ. Задача — провести разведочный анализ (EDA) и выявить закономерности в поведении клиентов банка, связанные с их оттоком.

## 📌 Цель проекта

Визуализировать данные об оттоке клиентов банка и выявить ключевые факторы, влияющие на уход клиентов. Определить, какие характеристики клиента (баланс, возраст, пол, страна, зарплата и т.д.) вносят наибольший вклад в отток.

## 📁 Данные

- **Источник:** учебный датасет, НИУ ВШЭ (`churn.csv`)
- **Размер:** 10 000 строк, 14 столбцов
- **Основные поля:**
  - `RowNumber` — номер строки таблицы
  - `CustomerId` — идентификатор клиента
  - `Surname` — фамилия клиента
  - `CreditScore` — кредитный рейтинг клиента (чем выше, тем больше кредитов клиент брал и возвращал их)
  - `Geography` — страна, из которой клиент (банк межнациональный)
  - `Gender` — пол клиента
  - `Age` — возраст клиента
  - `Tenure` — сколько лет клиент пользуется банком
  - `Balance` — сколько у клиента денег на счетах в банке
  - `NumOfProducts` — число услуг банка, которые приобрёл клиент
  - `HasCrCard` — есть ли у клиента кредитная карта (1 — да, 0 — нет)
  - `IsActiveMember` — есть ли у клиента статус активного участника банка (1 — да, 0 — нет)
  - `EstimatedSalary` — предполагаемая заработная плата клиента
  - `Exited` — статус ушедшего (1 — ушедший клиент, 0 — лояльный клиент) — **целевая переменная**

## 🎯 Основные выводы (для бизнеса)

1. **География — критический фактор оттока:**
   Германия демонстрирует самый высокий процент оттока (~32%) при относительно небольшой доле клиентов, тогда как Франция и Испания показывают значительно более низкие показатели. Это сигнал о проблемах с продуктом или сервисом именно на немецком рынке.

2. **Биполярное распределение баланса:**
   Значительная часть клиентов имеет нулевой баланс, а среди клиентов с положительным балансом распределение близко к нормальному. Баланс является важным сегментирующим признаком — клиенты с высоким балансом уходят чаще.

3. **Возраст — сильный предиктор оттока:**
   Процент оттока резко возрастает с увеличением возраста клиента, достигая пика в районе 45–60 лет. Молодые клиенты (до 30) уходят реже.

4. **Пол влияет на отток и баланс:**
   Женщины демонстрируют более высокий процент оттока (~25%) по сравнению с мужчинами (~16%), а также имеют более высокий средний баланс на счетах.

5. **Распределение по странам неравномерно:**
   Франция — самая представленная страна (≈50% клиентов), за ней следуют Германия и Испания. Однако именно в Германии отток наиболее высок.

## 🧠 Гипотезы, проверенные в проекте

- **География влияет на отток:** Германия — проблемный рынок с повышенным оттоком.
- **Возраст — сильный предиктор:** чем старше клиент, тем выше вероятность ухода (до определённого пика).
- **Пол влияет на отток:** женщины уходят чаще мужчин.
- **Баланс связан с оттоком:** клиенты с высоким балансом более склонны к уходу.
- **Распределение баланса биполярно:** большая группа клиентов с нулевым балансом и группа с нормально распределённым положительным балансом.
